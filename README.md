# 네이버쇼핑 SEO 가이드 & 실행 도구

AI Builders Lab의 비공식 교육용 네이버쇼핑 SEO 리서치와 브라우저 실행 도구입니다.

**운영 주소:** https://aihubos.github.io/naver-shopping-seo/

## 구성

- 공식 근거를 중심으로 정리한 랭킹 구조, 대행사 선택, 제재 사례, 변화 및 실행 로드맵
- 상품명 작성 점검: 길이·중복·홍보 문구 후보·기호 사용의 네 가지 참고 항목
- 13개 기본기 체크리스트, 완료율과 다음 할 일, 기존 진행 상황 마이그레이션
- CTR·CVR·ROAS·주문당 광고비 계산기
- 가이드 검색, 출처 검색·유형 필터, Markdown 진단 기록 다운로드, 인쇄/PDF 저장
- 고정 목차와 모바일 목차, 키보드 탭 이동, 모션 감소 설정 지원

점검 결과는 네이버의 공식 점수 또는 순위 예측이 아닙니다. 수치가 높은 상품의 상위 노출을 보장하지 않습니다. 콘텐츠 업데이트 기준일은 2026-11-01(KST)이며, 예정된 정책은 예정으로 구분합니다.

## 실행

빌드와 패키지 설치가 필요 없는 HTML/CSS/JavaScript 프로젝트입니다.

```sh
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다. 파일을 직접 여는 것보다 HTTP로 확인하는 편이 저장·다운로드 동작을 점검하기 좋습니다.

```sh
node --test tests/seo-core.test.cjs
node --check assets/main.js
node --check assets/seo-core.js
```

순수 계산·입력 검증·저장 데이터 해석을 테스트합니다. 브라우저에서는 제목 입력, 탭의 방향키 이동, 체크리스트 새로고침 복원, 검색 결과 이동, 출처 필터, 예시 지표와 0 분모, 다운로드, 모바일 화면을 확인합니다.

## 데이터 처리

- 체크리스트 상태만 브라우저 `localStorage`에 저장합니다. 동일 브라우저에서 한 상품을 점검하는 기록이며, 기기 간 동기화는 제공하지 않습니다.
- 상품명과 광고 성과 수치는 저장하거나 서버로 전송하지 않습니다. 새로고침하면 초기화됩니다.
- 다운로드 버튼을 누르면 현재 입력한 상품명과 점검 기록이 사용자의 기기에 Markdown 파일로 저장됩니다.
- 분석 추적 코드, 로그인, 외부 API 또는 자동 순위 조회 기능은 없습니다. 웹폰트는 jsDelivr에서 불러옵니다.
- 출처 링크를 열면 해당 외부 사이트로 이동합니다.

## 배포와 유지보수

GitHub Pages의 기존 `main` 브랜치 루트 게시 구성을 사용합니다. `index.html`, `assets/`, `.nojekyll`을 유지하고 상대 경로를 사용하세요. `.openai/`와 `dist/`는 작업용 미리보기 파일이며 배포 소스에 포함하지 않습니다.

수정 시 `index.html`의 자산 버전 쿼리(`?v=`)를 함께 올려 오래된 CSS/JavaScript 캐시가 섞이지 않도록 합니다. 정책·법령 관련 내용은 해당 공식 출처의 적용일과 확인 범위를 다시 검토합니다.

기존 앵커 `#summary`, `#ranking`, `#agency`, `#risk`, `#change`, `#action`, `#tools`, `#faq`, `#sources`는 유지합니다.
